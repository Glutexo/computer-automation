# Computer Automation

Repository for experiments, tooling, and documentation related to computer automation.

## Objectives

- Build reliable automation workflows for common computer tasks.
- Capture decisions, constraints, and implementation notes as the project evolves.
- Keep operational knowledge easy to find so future work starts with current context.

## Documentation

- `docs/project-rules.md` defines working rules for the repository.
- `docs/decision-log.md` records notable technical and product decisions.
- `docs/research-notes.md` stores findings, open questions, and implementation notes.

## Current app

- The repository currently contains a minimal Swift executable application.
- The first runnable slice is a simple greeting used to verify the local Swift toolchain and repository workflow.

## Run

```bash
swift run
```

## Working model

1. Update documentation when goals, constraints, or architecture change.
2. Record important observations while implementing, not after memory fades.
3. Prefer small, verifiable increments over broad speculative design.
